## STATE TRANSITIONS

### Sidebar Closed → Open
```
Click [☰]
  ↓
JavaScript: sidebar.classList.add("active")
  ↓
CSS: .sidebar.active { left: 0; }
  ↓
Sidebar slides from left into view
```

### Sidebar Open → Closed
```
User clicks outside
OR presses ESC
  ↓
JavaScript: sidebar.classList.remove("active")
  ↓
CSS: .sidebar { left: -300px; }
  ↓
Sidebar slides back to left (off-screen)
```

## JAVASCRIPT EXECUTION FLOW

### On Page Load
```
1. Get elements: sidebarToggle, sidebar
2. Log to console: "Sidebar Debug: {sidebarToggle, sidebar}"
3. Add click listener to button
4. Add outside-click listener to document
5. Add ESC-key listener to document
6. Log: "Sidebar toggle initialized successfully"
```

### On Button Click
```
1. Event fires: click on sidebarToggle
2. Stop propagation: e.stopPropagation()
3. Log: "Sidebar toggle clicked"
4. Toggle class: sidebar.classList.toggle("active")
5. Check state: contains("active")?
6. Log: "Sidebar now: OPEN" or "CLOSED"
```

### On Outside Click
```
1. Event fires: click anywhere on document
2. Check: Is sidebar open? (has .active class?)
3. Check: Is click outside sidebar and button?
4. If YES → Remove .active class
5. Log: "Sidebar closed (outside click)"
6. If NO → Do nothing
```

### On ESC Key
```
1. Event fires: keydown
2. Check: Key === "Escape"?
3. Check: Is sidebar open? (has .active class?)
4. If YES → Remove .active class
5. Log: "Sidebar closed (ESC key)"
6. If NO → Do nothing
```
