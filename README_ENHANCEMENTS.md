## 🚀 HOW TO USE

### Step 1: Hard Refresh Browser
```
Windows/Linux: Ctrl + Shift + R
Mac: Cmd + Shift + R
```

### Step 2: Click Any Song
Watch the visualizer animate!

### Step 3: Explore Sidebar
Click ☰ to see 5 tabs:
- Queue - See next songs
- History - View played songs
- Lyrics - Read lyrics
- Stats - Check your stats
- Playlists - Create playlists

### Step 4: Try New Controls
- 🔗 Share - Share on social media
- ➕ Add - Add to playlist
- 🎛️ EQ - Open equalizer
