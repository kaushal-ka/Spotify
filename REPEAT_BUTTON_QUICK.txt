# 🎚️ REPEAT BUTTON - QUICK VISUAL GUIDE

## 3 States with Clear Labels

### OFF State (Repeat Disabled)
```
┌─────────────────┐
│  [↻]     OFF    │
│  (white)        │
└─────────────────┘
   Gray badge
   Repeat is OFF
   No songs repeat
```

### ALL State (Repeat All Songs)
```
┌─────────────────┐
│  [↻]     ALL    │
│ (GREEN!)        │
└─────────────────┘
   Green glowing badge
   Repeat is ON (ALL mode)
   Playlist repeats
```

### ONE State (Repeat One Song)
```
┌─────────────────┐
│  [↻]     ONE    │
│ (GREEN!)        │
└─────────────────┘
   Green glowing badge
   Repeat is ON (ONE mode)
   Current song repeats
```

---

## How to Use

### Click Button (or Press 'R' Key)
```
OFF  →  ALL  →  ONE  →  OFF  →  ALL  →  ...
```

### Hover Over Button
```
Tooltip appears:
┌────────────────────────────┐
│ Repeat: OFF                │
│ Click to repeat all songs  │
└────────────────────────────┘
```

---

## Color Legend

| Color | Meaning |
|-------|---------|
| **White** | Inactive/OFF |
| **Green** | Active (ALL or ONE) |
| **Green Glow** | Mode is enabled |

---

## Badge Text

| Badge | Meaning |
|-------|---------|
| **OFF** | Repeat disabled |
| **ALL** | Repeat all songs |
| **ONE** | Repeat one song |

---

## What Each Mode Does

### OFF
- No repeat
- Playlist plays once
- Then stops

### ALL
- Repeats entire playlist
- After last song, plays first again
- Continues forever

### ONE
- Repeats current song
- Only this song repeats
- Other songs in queue don't play

---

## Quick Test

1. **Click button** → Badge changes OFF → ALL
2. **Hover over button** → Tooltip shows "Repeat: ALL songs"
3. **Click again** → Badge changes ALL → ONE
4. **Hover again** → Tooltip shows "Repeat: ONE song"
5. **Click again** → Badge changes ONE → OFF
6. **Or press 'R' key** → Same cycling
